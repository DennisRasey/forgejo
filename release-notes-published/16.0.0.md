Learn more about most notable changes and addressing the breaking changes in our news post: [Forgejo v16.0 is available](https://forgejo.org/2026-07-release-v16-0/).

Git hooks are now stored in a centralized location instead of being duplicated in every repository, and Git hook example files are no longer generated for new repositories. While a backwards-compatible change, your instance can benefit from [following an upgrade guide](https://forgejo.org/docs/v16.0/admin/upgrade/#hooks) to clean up these files for the existing repositories. As always, make sure you to have a usable backup before upgrading!
